# TehSticker Site — MVP v4

نسخه‌ی استاتیک و ریسپانسیو فروشگاه TehSticker.

## امکانات
- پک آماده: ۹۵ هزار تومان، طرح ثابت و تعداد متغیر
- پک شخصی: ۱۲۹ هزار تومان
- طراحی اختصاصی: ۱۷۹ هزار تومان
- پنل محلی برای اضافه/حذف کردن محصولات آماده
- ثبت‌نام محلی + کد ۱۰٪ خرید اول `TEHFIRST10`
- آپلود و پیش‌نمایش تا ۱۰ عکس برای سفارش‌های شخصی
- نحوه ارسال:
  - پست: ۱۳۴ هزار تومان و اضافه‌شدن خودکار به جمع سفارش
  - تهران با پیک: پس‌کرایه
- ساخت متن سفارش و Share Sheet موبایل
- ذخیره پیش‌نویس روی مرورگر

## اجرا
فایل `index.html` را باز کنید یا پوشه را روی یک سرویس static hosting قرار دهید.

> ثبت‌نام، سفارش‌ها و محصولات در این MVP هنوز به دیتابیس/درگاه پرداخت متصل نیستند.
